## 🔍 GOOGLE SEARCH CONSOLE SETUP

### **Step-by-Step Guide**

#### **1. Verify Ownership**
Choose one method:

**Method A: HTML File Upload**
```
1. Download verification file from Search Console
2. Upload to: /static/google-verification.html
3. Access at: sms.pastmaster.top/google-verification.html
4. Click "Verify" in Search Console
```

**Method B: DNS Verification**
```
1. Get TXT record from Search Console
2. Add to your domain's DNS settings in cPanel
3. Wait for DNS propagation (up to 48 hours)
4. Click "Verify" in Search Console
```

**Method C: HTML Tag** (Easiest)
```html
<!-- Add to <head> section of base template -->
<meta name="google-site-verification" content="YOUR_VERIFICATION_CODE" />
```

#### **2. Submit Sitemap**
```
1. In Search Console, go to "Sitemaps"
2. Enter: sitemap.xml
3. Click "Submit"
4. Wait for Google to process (24-48 hours)
```

#### **3. Request Indexing**
```
1. Go to "URL Inspection"
2. Enter your homepage URL
3. Click "Request Indexing"
4. Repeat for important pages:
   - /about/
   - /admissions/
   - /academics/
   - /contact/
   - /gallery/
```

#### **4. Monitor Performance**
Check weekly:
- **Performance**: Clicks, impressions, CTR, position
- **Coverage**: Indexed pages, errors, warnings
- **Enhancements**: Mobile usability, Core Web Vitals
- **Links**: Internal and external links

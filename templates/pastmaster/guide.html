Illustrated guide

Connect and use PastMaster

This school portal remains the source of learner records and official report cards. PastMaster independently provides exam practice and sends evidence-backed learning intelligence back to the school.

Open connection settingsView requirements

Before you start

  • Administrator access to this school portal
  • A PastMaster school-admin account
  • The PastMaster HTTPS address
  • Stable student or admission IDs

Independent by design

  • No database or learner password is shared
  • Cached reports remain visible during an outage
  • PastMaster still supports direct learner login
  • Disconnecting does not delete either system's data

1.Create credentials in PastMaster

A PastMaster school administrator opens SMS Connections, creates a connection, and copies the Client ID and one-time Client Secret. PastMaster will not display that secret again.

2.Save and test the connection

Open School Admin → PastMaster, paste the address and credentials, save, then select Test connection.

3.Synchronize learners

Select Synchronize learners. Stable student IDs map each school learner to one PastMaster account, so repeating the operation updates names, classes, and active status without creating duplicates.

4.Learners sign in and practise

A learner selects Practise with PastMaster on the student dashboard. The portal requests a ten-minute, single-use code. The learner enters it in the PastMaster app under Sign in from school SMS. The school password never leaves this portal.

5.Use learning intelligence

Use Process new events for learners with new activity, or Refresh all intelligence for the whole school. Teachers can open a learner's report to see recent attempts, measured mastery, trends, priority weaknesses, and suggested intervention.

These are advisory practice indicators, not official examination grades.

6.Keep reports updated automatically

Schedule python manage.py sync_pastmaster every five minutes. It processes changed learners and refreshes the complete roster at least every 24 hours.

7.Disconnect safely

Selecting Disconnect removes this portal's encrypted connection credential and stops new data exchange. Existing SMS learner records, cached intelligence, PastMaster learner profiles, and practice history are retained.

Troubleshooting: test the connection, confirm the PastMaster address uses HTTPS, synchronize the roster before learner sign-in, and ask the PastMaster administrator to rotate the Client Secret if it is lost or exposed.
